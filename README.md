# Employee Attrition Dashboard

This Power BI dashboard provides insights into employee attrition patterns and trends. The key features include:

- Attrition Rate: Displays the percentage of employees who left the company during a specific period.
- Attrition by Gender: A breakdown of attrition based on gender (male and female).
- Attrition by Age Group: Highlights how attrition is distributed across different age groups.
-  Metrics: Summary cards showing the total number of employees, employees who left, and active employees.

## Purpose
The dashboard is designed to help HR teams and managers:
1. Analyze employee turnover.
2. Identify trends and potential areas for intervention.
3. Improve employee retention strategies.

 Technologies Used
- Power BI: For creating and visualizing the dashboard.




How to Use
1. Open the `.pbix` file in Power BI Desktop.
2. Refresh the data sources to see updated results.
3. Explore the visualizations and filters to gain insights.
